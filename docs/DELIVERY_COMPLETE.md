## 🔧 Easy to Customize

### Add New Concepts
Edit `src/store/learningStore.js`:
```javascript
// Add to INITIAL_NODES array
{ id: 'your-concept', label: 'Your Topic', ... }

// Add to INITIAL_EDGES for prerequisites
{ source: 'prerequisite', target: 'your-concept', strength: 0.85 }

// Add quiz questions to QUIZ_DATABASE
'your-concept': [{ q: '...', options: [...], correct: 0 }]
```

### Change Theme Colors
Edit `src/index.css`:
```css
:root {
  --color-primary: #YOUR-CYAN;
  --color-accent: #YOUR-PURPLE;
}
```

### Adjust Animations
All animations are in component `.css` files. Easy to modify timing, delays, intensities.
